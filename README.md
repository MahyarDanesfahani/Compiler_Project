# فاز اول پروژه کامپایلر: تحلیل لغوی

این پروژه یک اسکنر (تحلیل‌گر لغوی) برای زیرمجموعه کوچکی از زبان NovaScript+ است که با Python نوشته شده. اسکنر کد را کاراکتر به کاراکتر می‌خواند و به توکن تبدیل می‌کند.

جدول انتقال DFA در فایل `transition_table.csv` است و برنامه موقع اجرا آن را می‌خواند. برای تعیین حالت‌ها از `if/else` استفاده نشده و فقط از جدول جستجو می‌شود.

## اجرا

```
python ui.py                          # رابط گرافیکی
python scanner.py samples/valid.ns    # اجرا در ترمینال
```

به نصب چیزی نیاز نیست. اگر `python` کار نکرد، `python3` یا `py` را امتحان کنید.

## فایل‌ها

- `scanner.py`: اسکنر
- `transition_table.csv`: جدول انتقال DFA
- `ui.py`: رابط گرافیکی
- `nfa_dfa.md`: عبارت منظم، NFA و تبدیل آن به DFA
- `nfa.dot`, `dfa.dot`: شکل NFA و DFA (تصویرشان در پوشه `diagrams`)
- `samples/`: برنامه‌های تست. سه فایل `valid`, `arithmetic`, `identifiers` بدون خطا هستند و دو فایل `invalid`, `errors` خطای لغوی دارند.
- `presentation_notes.md`: یادداشت‌های ارائه

## چه چیزهایی را تشخیص می‌دهد

- شناسه: حروف انگلیسی و `_` و رقم، که با رقم شروع نشود
- عدد صحیح
- `+` و `=` و `(` و `)`
- کلمه‌های کلیدی `int` و `if`

فاصله، Tab و خط جدید نادیده گرفته می‌شوند. هر کاراکتر دیگری خطای لغوی است. خطا با شماره خط و ستون نشان داده می‌شود و اسکنر بعد از آن ادامه می‌دهد.

## چیزهایی که هنوز نداریم

- کامنت
- عدد اعشاری
- عملگرهای `-` و `*` و `/`
