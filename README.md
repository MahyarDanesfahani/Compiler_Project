# فاز اول کامپایلر NovaScript+

این پوشه تحویل فاز اول، یعنی تحلیل لغوی دستی، است.

## اجرا

```text
python scanner.py samples/valid.ns
python scanner.py samples/invalid.ns

برای اجرای رابط کاربری:

```text
python ui.py
```
```

اگر Python روی سیستم با دستور دیگری اجرا می‌شود، همان دستور را جایگزین `python` کنید.

## فایل‌های تحویلی

- `transition_table.csv`: جدول انتقال DFA که برنامه به‌صورت پویا می‌خواند.
- `scanner.py`: اسکنر دستی جدول‌محور، بدون Flex/PLY و بدون ماشین حالت hardcoded.
- `nfa_dfa.md`: عبارات منظم، توضیح NFA، DFA و جدول قابل ارائه.
- `samples/valid.ns`: ورودی معتبر نمونه.
- `samples/invalid.ns`: ورودی دارای خطای لغوی برای نمایش بازیابی خطا.
- `samples/identifiers.ns`: نمونهٔ شناسه‌ها.
- `samples/arithmetic.ns`: نمونهٔ عبارت محاسباتی.
- `samples/errors.ns`: نمونهٔ چندخطی با چند خطای لغوی.
- `ui.py`: رابط کاربری نمایش برنامه، توکن‌ها، خطاها و جدول DFA.

## نکات ارائه حضوری

1. ابتدا عبارات منظم و NFAهای رسم‌شده را روی کاغذ یا با ابزار رسم ارائه کنید.
2. نشان دهید NFA چگونه به DFA و سپس به `transition_table.csv` تبدیل شده است.
3. CSV را جلوی استاد تغییر دهید و ثابت کنید برنامه جدول را از فایل می‌خواند.
4. ورودی `invalid.ns` را اجرا کنید و توضیح دهید اسکنر پس از `@` متوقف نمی‌شود.
5. تفاوت شناسه `sum` با کلمات کلیدی `int` و `if` را توضیح دهید.
6. برای تحویل نهایی، خروجی اجرای هر دو نمونه و فایل‌های NFA/DFA را همراه پروژه نگه دارید.
